Roblox Studio 兒童入門學習計畫（8 週）

適合年齡：約 8 到 14 歲，年紀較小的孩子可以把進度放慢一倍。
建議頻率：每週 3 到 4 次，每次 30 到 45 分鐘。
最終目標：完成並發布一款自己的跑酷闖關遊戲（Obby），讓家人朋友一起玩。

開始前的準備

  • 電腦：Roblox Studio 只能在 Windows 或 Mac 電腦上使用，手機和平板不行。
  • 安裝：到 Roblox 官網登入帳號，下載並安裝 Roblox Studio（免費）。
  • 滑鼠：建議用滑鼠，用觸控板操作 3D 視角很辛苦。
  • 筆記本：準備一本「遊戲設計筆記」，畫關卡草圖、記點子。

第 1 階段：認識工具（第 1 到 2 週）

第 1 週：熟悉介面

  • 打開 Studio，選 Baseplate（空白地板）範本
  • 認識 4 個重要視窗：Explorer（物件總管）、Properties（屬性）、Toolbox（工具箱），以及視角操作（按住右鍵轉視角，W、A、S、D 移動）
  • 用 Part（方塊） 練習 Move、Scale、Rotate 三個工具
  • 按 Play 測試，走進自己蓋的世界

小任務：蓋一間有屋頂、門和窗戶的小房子。

第 2 週：蓋第一個跑酷關卡

  • Anchored（固定）：勾選後方塊才不會掉下去，這是新手最常忘記的設定
  • 改變 Color（顏色） 和 Material（材質）
  • 用 SpawnLocation（重生點） 設定出發位置
  • 設計跳台：寬窄、高低、間距的變化

小任務：做一條有 10 個跳台的跑酷路線，請家人試玩。

第 2 階段：寫第一行程式（第 3 到 5 週）

第 3 週：認識程式（Luau）

在方塊上按 ＋ → Script，新增一個程式。打開 Output（輸出） 視窗看結果：

print("哈囉，我的第一個遊戲！")

用程式改變方塊：

local part = script.Parent
part.BrickColor = BrickColor.new("Bright red")
part.Transparency = 0.5

重要觀念：local 用來建立變數，可以想成貼了名字的盒子，用來存放東西。

小任務：用程式讓方塊每隔 1 秒換一次顏色（提示：while true do 和 task.wait(1)）。

第 4 週：碰到就失敗的「熔岩方塊」

事件（Event）：當某件事發生時執行程式；if 判斷：符合條件才執行。

local part = script.Parent

part.Touched:Connect(function(hit)
	local humanoid = hit.Parent:FindFirstChild("Humanoid")
	if humanoid then
		humanoid.Health = 0
	end
end)

有東西碰到方塊時，檢查它是不是玩家角色；如果是，就讓角色的血量歸零。

小任務：把熔岩方塊改成紅色霓虹材質，放進跑酷關卡裡。

第 5 週：會動的機關

  • 消失再出現的平台：Transparency 搭配 CanCollide（能不能站上去）
  • 用 TweenService 讓平台來回移動
  • 加入 Checkpoint（檢查點）：多放幾個 SpawnLocation

小任務：在關卡裡加入 3 種機關：消失平台、移動平台和熔岩地板。

第 3 階段：讓遊戲更完整（第 6 到 7 週）

第 6 週：收集金幣與排行榜

步驟 1：在 ServerScriptService 新增 Script，建立排行榜：

game.Players.PlayerAdded:Connect(function(player)
	local leaderstats = Instance.new("Folder")
	leaderstats.Name = "leaderstats"
	leaderstats.Parent = player

	local coins = Instance.new("IntValue")
	coins.Name = "Coins"
	coins.Value = 0
	coins.Parent = leaderstats
end)

步驟 2：做一個黃色金幣，在金幣裡新增 Script：

local coin = script.Parent
local canCollect = true

coin.Touched:Connect(function(hit)
	local player = game.Players:GetPlayerFromCharacter(hit.Parent)
	if player and canCollect then
		canCollect = false
		player.leaderstats.Coins.Value += 1
		coin.Transparency = 1
		task.wait(5)
		coin.Transparency = 0
		canCollect = true
	end
end)

重要觀念：canCollect 是一個「開關」，防止玩家碰一下就被重複計算很多次。

小任務：在關卡各處藏 10 枚金幣，難拿的地方放多一點。

第 7 週：音效、畫面和美化

  • 加入 Sound（音效）：撿金幣的聲音、背景音樂
  • 用 ScreenGui 和 TextLabel 顯示文字，例如「恭喜過關！」
  • 調整 Lighting（光線）：白天、黃昏、夜晚
  • 從 Toolbox 加入樹木、裝飾等素材

Toolbox 裡別人做的素材可能藏有惡意程式。只用 Roblox 官方或評價高的素材，放進來後檢查裡面有沒有可疑的 Script。

第 4 階段：發布遊戲（第 8 週）

  • File → Publish to Roblox 發布遊戲
  • 取遊戲名稱、寫介紹、做縮圖
  • 先設成私人或僅限好友

小任務：

  1. 邀請 3 位家人或朋友試玩
  2. 問他們：哪裡最好玩？哪裡太難？哪裡有 bug？
  3. 根據回饋修改，發布第 2 版

完成 8 週後，孩子就有一款完全自己做的遊戲了！

推薦學習資源

  • Roblox Creator Hub：官方教學文件和入門課程
  • Studio 內建 AI 助手（Assistant）：可以問程式問題，但鼓勵孩子先自己想
  • YouTube：搜尋「Roblox Studio 教學」或「Roblox Studio tutorial」，例如 TheDevKing、AlvinBlox
  • Roblox Education：官方免費課程，適合學校和家長

給家長的陪伴建議

  1. 不懂程式也沒關係：當孩子的「第一位玩家」，給真心的回饋。
  2. 鼓勵試錯：教孩子看 Output 視窗的錯誤訊息，自己找問題。
  3. 重視過程：誇獎「這個機關設計得很聰明」，不要只問「有多少人玩」。
  4. 讓孩子自己做決定：主題、顏色、關卡設計都由他決定。
  5. 注意安全：發布遊戲時不要填真實姓名、學校等個人資料。

學完之後可以挑戰

  • 第二款遊戲：逃脫房間、塔防遊戲或模擬經營遊戲
  • 進階程式：DataStore（存檔）、RemoteEvent（玩家和伺服器溝通）
  • 參加遊戲開發比賽（Game Jam）
